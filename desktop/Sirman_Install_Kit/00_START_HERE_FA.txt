بسته نصب سیرمان روی ویندوز
==========================

اول این را بخوانید: فایل یک‌کیلوبایتی داخل پوشه updates برنامه نیست.
برنامه واقعی Sirman_Final.html است (حدود ۱٫۶ مگابایت).

راهنمای کامل از صفر (نصب روی کامپیوتر جدید):
  راهنمای_نصب_از_صفر.txt
  راهنمای_نصب_و_آپدیت.docx

مسیر همین پوشه را کامل روی ویندوز کپی کنید.

۱) پیش‌نیاز ساخت exe:
   - .NET 8 SDK
   - WebView2 Runtime (معمولاً با Edge هست)

۲) دوبارکلیک:
   build-win.bat
   → پوشه publish و Sirman.exe ساخته می‌شود

۳) دوبارکلیک:
   نصب_سیرمان.bat
   → پوشه نصب را خودتان انتخاب می‌کنید
   → میانبر Start: «سیرمان»

۴) اجرا از منوی Start → سیرمان

نصب خیلی ساده‌تر بدون exe:
   Sirman_Start.bat یا Sirman_Final.html را دوبار کلیک کنید.

حذف سالم:
   Start → سیرمان → حذف سیرمان
   یا Uninstall-Sirman.bat
