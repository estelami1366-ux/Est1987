راهنمای نصب سیرمان دسکتاپ (فاز ۱ + فاز ۲)
========================================

این پوشه همه چیزهایی است که باید «کنار هم» باشند.

────────────────────────────────────────
الف) محتویات بسته (همین پوشه)
────────────────────────────────────────
Sirman_Install_Kit/
├── Sirman_Final.html              ← برنامه اصلی (HTML)
├── Sirman_Final_1405.5.20γ.html   ← نسخه شماره‌دار (اختیاری)
├── Sirman_Pending_Update.json     ← آپدیت کامل (اختیاری؛ برای اعمال خودکار)
├── updates/                       ← آپدیت‌های اضافی (اختیاری)
├── build-win.bat                  ← ساخت Sirman.exe روی ویندوز
├── install-sirman.bat             ← نصب در AppData + میانبر Start + حذف
├── Uninstall-Sirman.bat           ← حذف سالم برنامه (کنار هر نصب/بیلد کپی می‌شود)
├── apply_sirman_update.ps1        ← آپدیت از طریق اسکریپت (اختیاری)
├── README.md
└── Sirman.Desktop/                ← سورس پوسته .NET
    ├── Sirman.Desktop.csproj
    ├── Program.cs
    ├── MainForm.cs
    ├── NotifyBridgeService.cs     ← پل اعلان ویندوز (۸۷۶۶)
    ├── AppPaths.cs
    ├── UpdateService.cs
    ├── InstallService.cs
    ├── app.manifest
    └── README.md

بعد از build-win.bat این هم ساخته می‌شود:
└── publish/
    └── Sirman.exe                 ← فایل اجرایی ویندوز

────────────────────────────────────────
ب) پیش‌نیاز روی هر کامپیوتر ویندوز
────────────────────────────────────────
1) .NET 8 SDK
   https://dotnet.microsoft.com/download/dotnet/8.0
   (فقط برای ساخت لازم است؛ اگر از قبل publish آماده دارید، روی سیستم نهایی فقط Runtime کافی است)

2) WebView2 Runtime
   معمولاً با Microsoft Edge نصب است.
   در صورت نبود:
   https://developer.microsoft.com/microsoft-edge/webview2/


────────────────────────────────────────
نصب پکیج با انتخاب مسیر (پیشنهادی)
────────────────────────────────────────
1) build-win.bat
2) نصب_سیرمان.bat  (یا install-sirman.bat)
   → پنجره انتخاب پوشه باز می‌شود
   → فقط در مسیر انتخابی شما نصب می‌شود
   → کنار پوشه تحویل/سورس کپی نمی‌شود
3) میانبر Start: «سیرمان» و «حذف سیرمان»

────────────────────────────────────────
ج) نصب روی یک سیستم (پیشنهادی)
────────────────────────────────────────
1) کل پوشه Sirman_Install_Kit را روی ویندوز کپی کنید
   (مثلاً D:\Sirman_Install_Kit)

2) داخل پوشه، دوبارکلیک:
   build-win.bat
   → پوشه publish و Sirman.exe ساخته می‌شود

3) بعد دوبارکلیک:
   install-sirman.bat
   → کپی می‌شود به:
      %LOCALAPPDATA%\Sirman\App
   → میانبر منوی Start با نام «سیرمان» ساخته می‌شود
   → میانبر «حذف سیرمان» و فایل Uninstall-Sirman.bat هم کنارش ساخته می‌شود

4) از منوی Start برنامه «سیرمان» را باز کنید.
   برای حذف: Start → سیرمان → حذف سیرمان
   یا فایل Uninstall-Sirman.bat کنار exe

────────────────────────────────────────
د) نصب سریع بدون install-sirman (دستی)
────────────────────────────────────────
1) build-win.bat را اجرا کنید
2) این فایل‌ها را داخل publish کنار هم بگذارید:
   - Sirman.exe  (ساخته‌شده)
   - Sirman_Final.html
   - (اختیاری) Sirman_Pending_Update.json
3) Sirman.exe را اجرا کنید

────────────────────────────────────────
ه) نصب روی ۲۰۰ سیستم
────────────────────────────────────────
روش ۱ (ساده‌ترین):
- یک‌بار روی یک سیستم build بگیرید
- کل پوشه publish را (به‌همراه Sirman_Final.html) روی USB/شبکه بدهید
- روی هر سیستم install-sirman.bat را از بسته اصلی بزنید
  یا فقط محتویات publish را در یک پوشه کپی و Sirman.exe را اجرا کنید

روش ۲ (آپدیت بعدی):
- فقط Sirman_Pending_Update.json را کنار Sirman.exe بگذارید
- برنامه را باز کنید → خودکار آپدیت می‌شود

────────────────────────────────────────
و) مسیرهای مهم بعد از نصب
────────────────────────────────────────
برنامه نصب‌شده:
  %LOCALAPPDATA%\Sirman\App\Sirman.exe

تنظیمات پوسته / بک‌آپ:
  %LOCALAPPDATA%\Sirman\

میانبر Start:
  منوی Start → سیرمان

────────────────────────────────────────
ز) منوهای داخل برنامه (فاز ۲)
────────────────────────────────────────
آپدیت  → اعمال آپدیت در انتظار / انتخاب فایل JSON
بک‌آپ  → انتخاب پوشه بک‌آپ / کپی HTML
نصب    → نصب در این کاربر + میانبر Start
پرونده → انتخاب HTML / باز کردن پوشه‌ها

────────────────────────────────────────
ح) اگر باز نشد
────────────────────────────────────────
- WebView2 نصب باشد
- Sirman_Final.html کنار Sirman.exe باشد
- اگر .NET Runtime کم است، پیام خطا می‌دهد؛ Desktop Runtime 8 را نصب کنید

────────────────────────────────────────
ط) اعلان دسکتاپ (مرکز اعلان ویندوز)
────────────────────────────────────────
در Sirman.exe پل اعلان خودکار روشن می‌شود (پورت ۸۷۶۶).

1) برنامه را باز کنید
2) بروید به «وظایف و یادآوری»
3) «🔔 فعال‌سازی اعلان دسکتاپ» را بزنید
   → نیازی به Allow مرورگر نیست
4) برای تست دستی: منوی راهنما → آزمایش اعلان ویندوز


════════════════════════════════════
رفع بستن پنجره (۱۴۰۵.۵.۲۰ζ)
════════════════════════════════════
اگر بعد از بله/خیر بک‌آپ، پنجره بسته نمی‌شود:
1) حتماً Sirman.exe را دوباره بسازید (آپدیت HTML به‌تنهایی کافی نیست):
     build-win.bat
     install-sirman.bat
2) Sirman_Pending_Update.json را کنار exe بگذارید و یک‌بار exe را باز کنید.

اگر دکمه ارور داد، HTML را به نسخه ۱۴۰۵.۵.۲۰γ (یا جدیدتر) آپدیت کنید
و مطمئن شوید Focus Assist ویندوز اعلان‌ها را مسدود نکرده است.

────────────────────────────────────────
ط) آپدیت برای Sirman.exe
────────────────────────────────────────
فایل Sirman_Pending_Update.json را کنار Sirman.exe بگذارید و برنامه را باز کنید.
یا از منوی آپدیت → انتخاب فایل JSON:
  updates/Sirman_Update_1405.5.20γ.json

هنگام بستن پنجره، درباره بک‌آپ می‌پرسد.
