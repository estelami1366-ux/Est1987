# Est1987 — لایق الکترونیک پارسیان

## اجرای رسمی (ویندوز)

فقط از **`Sirman_Start.bat`** استفاده کنید (سرور محلی + پل اعلان مرکز اعلان ویندوز).

برای میانبر Start/دسکتاپ یک‌بار **`نصب_میانبر_سیرمان.bat`** را اجرا کنید.

مسیر پوستهٔ .NET / `Sirman.exe` کنار گذاشته شده است — برنامه همان فایل HTML تک‌فایلی است.

نرم‌افزار خدمات پس از فروش (HTML تک‌تکه) + فضای کاری AutoClaw.

## نسخهٔ فعلی
سیرمان: **`Sirman_Final.html` → ۱۴۰۵.۵.۲۰α** — اجرا با `Sirman_Start.bat`

## دستورهای مهم
```bash
node test_laegh.js Laegh_Final.html
node build.js                 # نیاز به codes.10.4.6/ هم‌خوان با split.js

```
