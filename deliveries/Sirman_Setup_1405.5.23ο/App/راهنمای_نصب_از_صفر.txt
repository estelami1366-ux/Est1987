﻿﻿راهنمای نصب سیرمان از صفر — کیت Setup
لایق الکترونیک پارسیان
نسخه جاری: ۱۴۰۵.۵.۲۳ξ  (1405.5.23ο)
تاریخ: ۱۴۰۵/۰۵/۲۳

فایل‌ها را یکی‌یکی کپی‌پیست نکنید.


════════════════════════════════════
۱) کیت کامل — فقط همین را انجام دهید
════════════════════════════════════

۱) فایل Sirman_Setup_1405.5.23ο.zip را بگیرید.
۲) روی zip راست‌کلیک کنید → Extract All (استخراج همه).
۳) داخل پوشهٔ استخراج‌شده فقط روی نصب.bat
   (یا SETUP.bat) دوبار کلیک کنید.
۴) پوشه نصب را انتخاب کنید. پیشنهاد: Documents\Sirman
۵) اگر میانبر دسکتاپ خواست، بگویید Yes.
۶) از منوی Start یا آیکون دسکتاپ «Sirman» را باز کنید.
۷) پایین منوی راست نسخه باید ۱۴۰۵.۵.۲۳ξ باشد.

همین. برنامه نصب شد.

اگر قبلاً نصب داشتید: همان کیت را دوباره بزنید و
همان پوشه قبلی را انتخاب کنید تا برنامه جایگزین شود.
قبلش از «ورود/خروج داده» بک‌آپ بگیرید.


════════════════════════════════════
۲) فایل یک‌کیلوبایتی برنامه نیست.
════════════════════════════════════

فایل یک‌کیلوبایتی (مثلاً داخل پوشه updates با پسوند json)
برنامه نیست. با بارگذاری‌اش چیزی نصب نمی‌شود.

برنامه واقعی داخل کیت، پوشه App است:
  Sirman_Final.html   حدود ۱٫۶ مگابایت
  Sirman.exe          پنجره ویندوز


════════════════════════════════════
۳) اگر Sirman.exe باز نشد
════════════════════════════════════

روی ویندوز .NET 8 Desktop Runtime لازم است.
اگر نبود، از پوشه نصب Sirman_Start.bat را بزنید
(برنامه در مرورگر باز می‌شود).

دانلود Runtime:
https://dotnet.microsoft.com/download/dotnet/8.0
گزینه Desktop Runtime 8 برای Windows x64.

WebView2 معمولاً با Microsoft Edge نصب است.


════════════════════════════════════
۴) داده کجاست
════════════════════════════════════

فاکتور و گارانتی داخل فایل HTML / exe نیست.
در حافظه همین کامپیوتر ذخیره می‌شود.

اگر برنامه را به کامپیوتر دیگر ببرید، آنجا خالی است
مگر بک‌آپ «ورود/خروج داده» را برگردانید.


════════════════════════════════════
۵) روش دستی (فقط اگر zip نداشتید)
════════════════════════════════════

این روش همان کپی‌پیست است و توصیه نمی‌شود.

Sirman_Final.html + Sirman_Start.bat را در یک پوشه بگذارید
و روی Sirman_Start.bat دوبار کلیک کنید.
برای آیکون: نصب_میانبر_سیرمان.bat گزینه ۲.


داخل برنامه: راهنما → آپدیت نرم‌افزار → نصب از صفر
