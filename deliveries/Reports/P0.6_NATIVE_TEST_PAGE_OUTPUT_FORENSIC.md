## 18. Could Print Center profile cause this output?

Profiles (`PRINT_PROFILE_DEFAULTS` `:24007`) set:

```text
printer, paper, orientation, margin, copies, pageRange, color, scale, duplex
```

They do **not** set `kind`.

`pcDoNativeTestPage` always builds `kind:'testPage'` after reading those fields. Selecting `A4 Office`, `Thermal`, or `Zebra` cannot route Test Page into `DrawPostalLabel`.

What a profile **can** do:

- Feed **A4** (or `label` / `80mm`) into **postal native** via `printEngineJob('postal')` inheriting `st.job`.
- Feed landscape into **Test Page** via `pcReadJobFromUI().orientation`.
- Print Center `🖨 چاپ` (`pcDoPrint`) is **invoice native** only when `lastDocId==='invoice'`; otherwise it needs `_pcLiveDoc.html` and goes **HTML/WebView2**, not `DrawPostalLabel`.

Print Center preview for `lastDocId==='postal'` is `printEngineBuildSample` (generic two-row table), **not** the 2×2 postal cards (`refreshPrintCenterPreview` `:24650`). So the Print Center preview cannot be the source of the four boxes.

**Profile routing does not turn Test Page into Postal Label.** It can make Postal Label print on A4.
