## Before / after layout

```text
BEFORE
  Address:  height 36, RtlFormat LineLimit + EllipsisCharacter
  Zip/tel:  height 16, LtrFormat NoWrap + EllipsisCharacter
  Person:   concatenated onto tel LTR value
  Name:     height 18 + ellipsis
  Fragile:  RtlFormat + EllipsisCharacter
  Y:        fixed +38 / +18 / +20

AFTER
  Address:  MeasureString wrap in remaining height minus reserved tail
            PostalRtlWrapFormat, Trimming.None
  Zip/tel:  DrawPostalIdBlock grows with wrapped LTR value
            AsLeftToRight still applied; 2000-35155 not reversed
  Person:   own RTL wrapped line after phone
  Name:     wrapped RTL, height from measure
  Fragile:  badge sized from wrap measure; clip if card bottom hit
  Y:        after each block: y += measuredHeight + 4
            after address: y = max(addrEnd, logoBottom) then clamp so tail fits
  2×2 geometry: unchanged
  Overflow: clip without "..." (StringTrimming.None)
```
