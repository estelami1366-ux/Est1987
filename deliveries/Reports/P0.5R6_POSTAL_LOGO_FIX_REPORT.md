## Exact logo source flow

```text
global logoSrc
  (data:…  OR  disk://sirman_media/logo.jpg  OR  local path)
    → printPostalNative()                         [HTML UNCHANGED]
    → printEngineBuildPostalLabelModel.logoSrc    [HTML UNCHANGED]
    → PrintDocument JSON
    → NativePrintRequest.PostalLabel.LogoSrc      [parser UNCHANGED]
    → NativeWindowsPrintService.Submit
         NativeLogoSource.Resolve(src, ExistingBackupMediaRoots(), BaseDirectory)
    → bytes → Image.FromStream → Bitmap
    → DrawPostalLabel → DrawPostalSenderCard
         if (logo is not null) DrawRoundRect + DrawImage   [geometry UNCHANGED]
```

Stored `logoSrc` is **not** rewritten to a data URL or a Windows path.

## Exact resolver used

`Sirman.Core.Printing.NativeLogoSource` — C# equivalent of HTML `isDiskRef` / `diskRefPath` / `writeDiskBlob` first-segment `sirman_media`.

| Kind | Behavior |
|---|---|
| `data:` | Base64 decode (same as previous `TryLogo`) |
| `disk://sirman_media/...` | Join relative path onto **existing** backup roots |
| local file name/path | Previous BaseDirectory search |
| `http:` / `https:` / `file:` | Reject (same as before) |
| missing file | `logo=null`, `failureReason=disk-missing` |
| bad bytes | `failureReason=image-decode-failed` (or unrecognized header in Core) |

**Media roots (read-only, no new folders created by the print path):**

1. `AppPaths.LoadSettings().BackupFolder` if that directory exists (Desktop backup picker)
2. `%LocalAppData%\Sirman\Backups` if it exists (AppPaths default)
3. `%AppData%\Sirman\backup` if it exists (`GetBackupDir` formula; Host autosave JSON)
4. `%LocalAppData%\Sirman` if it exists

Relative file: `{root}/sirman_media/logo.jpg` for `disk://sirman_media/logo.jpg`.  
`..` and rooted escapes are rejected.

Invoice still uses `TryLogo(Invoice.LogoDataUrl)` only. Test Page still has no logo.
