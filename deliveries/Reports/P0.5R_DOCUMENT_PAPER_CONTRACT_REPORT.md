## Paper architecture
```text
Document paper owner:
NativePrintPaper.DocumentDefaultPaper(kind)
  postalLabel → A5
  invoice     → A4 landscape
  testPage    → A4

Override owner:
printEngineOverrideJob(kind) — only when Print Center lastDocId
matches this document (postal|postalLabel / invoice / testPage).
Caller flags: paperExplicit, printCenterExplicit.
Postal page: getPrintSettings().postal.paper is the document setting
(PS_DEFAULTS.postal.paper = A5).

Resolved paper object:
ResolvedPaperSpec (Sirman.Core)
Consumed by:
  NativeWindowsPrintService.ApplyPaperSize
  PrintDocument.DefaultPageSettings.Landscape / Margins / Copies

Resolution precedence:
1. Explicit user document override (paperExplicit + paper token)
2. Explicit Print Center selection (lastDocId matches this document)
3. Document default paper specification
4. Installed driver form (P0.1 TrySelectInstalledIsoForm)
5. Controlled custom-size fallback (SIRMAN-* PaperSize / WithExplicitMillimeters)

A4 Office profile is NOT an override unless lastDocId is this document.
Unset paper does not become implicit A4.
```

Inspected leak (P0.6): `printPostalNative` used `printEngineJob('postal').paper`, and `printEnginePrintNative` preferred `job.paper` from A4 Office defaults, overwriting postal A5.

Smallest distinction for “explicit vs stored profile”:
`printEngineOverrideJob` returns paper only if `st.lastDocId` is this document.
A stored `lastByDoc.postalLabel` from an old leaked save is ignored while lastDocId is invoice.
