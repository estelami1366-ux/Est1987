---

## 6. Root cause

Print Center native forced a **custom GDI form** for A4/A5. Many laser/PCL drivers spool-accept `Print()` (hence `PRINT_SUBMITTED`) then fail at the driver form/tray. Label/thermal drivers commonly accept custom sizes, which matches Label SUCCESS.

This patch does **not** rewrite the native renderer. It only changes which `PaperSize` object is assigned for ISO A4/A5.
