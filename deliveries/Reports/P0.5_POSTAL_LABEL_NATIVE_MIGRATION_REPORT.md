## Postal label

Fields actually printed (from live `updatePostalPreview` / `printPostal`):

| Side | Printed | Not printed |
|---|---|---|
| Sender | addr, zip, tel, person, logo + brandEn | sender name (`#snd-name`) |
| Recipient | addr, zip, tel, name, note (fragile badge) | — |
| Page | four cards (2×2), A5/A4, 10mm margin | date, tracking/serial, barcode, QR |
| Settings | border, fragile visibility | `ps.postal.count` (saved, still unused) |
| Watermark | HTML CSS `body::before` via `printBgCss` | **not ported** (high-risk; left on HTML path) |

```text
Paper:        ps.postal.paper default A5 (A4 also valid)
              HTML printPostal fallback `pp.paper||'A4'` only if paper string empty
Width:        A5 148mm / A4 210mm via driver ISO form (P0.1)
              custom/label/80mm: optional widthMm → hundredths inch
Height:       A5 210mm / A4 297mm via driver ISO form
              custom/label/80mm: optional heightMm → hundredths inch
Orientation:  portrait unless job/orientation says landscape
Copies:       printEngineJob('postal').copies / Host copies (1..20)
Margin:       HTML @page 10mm → native ParseMarginMm("10mm") = 10mm
              → hundredths inch = round(10/25.4*100) then max(20, n)
Gap/offset:   HTML flex gap 10px ≈ 2.6mm; native card gap = 10 hundredths-inch
              (2.54mm). Documented conversion, not a guessed new layout.
```

`widthMm`/`heightMm` are ignored for ISO A4/A5 so P0.1 installed-form selection stays in charge.
