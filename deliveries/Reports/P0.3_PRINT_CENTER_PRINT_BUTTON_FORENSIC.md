## 5. How `چاپ` selects engine

Not a single flag. Exact conditions:

```text
1. pcDoPrint invoiceDoc?
     lastDocId === 'invoice'
     OR live _pcLiveDoc.docId === 'invoice' with lastDocId empty/invoice
   YES → printEnginePrintNative, payload.engine = 'native', kind = 'invoice'
   NO  → if live HTML → printEnginePrintHtml (no engine field, html present)
         else NO_DOCUMENT

2. SirmanHostObject.PrintDocument
     nativePaper = (engine === 'native' && purpose !== 'pdf')
                   OR (html empty && kind in {testPage, invoice} && purpose !== 'pdf')
     nativePaper true  → EnqueueNative (GDI)
     else if html      → Enqueue (WebView2)
```

Depends on **document identity** (`lastDocId` / `_pcLiveDoc`), not on profile title and not on HP vs PDF **unless** the printer name already failed the PDF check and returned before Host.

Profile `A4 Office` has **no** `engine`, **no** `destination`, **no** flags field. It cannot by itself select native vs WebView2.

`pcDoNativeTestPage` skips step 1 entirely.
