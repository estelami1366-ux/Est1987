## HTML-only caveat (do not over-claim)

This JSON replaces **HTML only** (`Sirman_Final.html`).

C# `NativePrintPaper` / `ResolvedPaperSpec` lives in `Sirman.exe`. This packet did **not** rebuild the Windows kit.

- After this HTML update, postal native still sends `paper: A5` from `printEngineDocumentDefaultPaper`.
- An old exe that still treats empty paper as A4 will not see empty paper on the postal path; current HTML sends A5.
- Full C# document-owned resolver (Print Center leak ignored unless lastDocId matches) requires the P0.5R exe from the product commit, not this JSON.
